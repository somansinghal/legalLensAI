TRANSPARENT ARCHITECTURE

Privacy Policy

Last updated: September 2026. LegalLens AI is engineered from the ground up around data minimization, strict isolation, and zero persistent storage of your raw legal text.

1. Core Privacy Architecture: The Transient Document Boundary

The single most important principle of LegalLens AI is our Transient Processing Architecture:

  • Raw Document Text is Never Persistently Stored: When you paste or upload an agreement for evaluation, the document text resides strictly in volatile server memory during the active inference request. It is never written to Cloud Firestore, disk logs, or database storage.
  • Isolated Structured Output: Once analyzed, only normalized insights (such as plain-language summaries, attention levels, extracted deadlines, and interactive checklist items) are stored in your private user subcollection.
  • No Machine Learning Training: Your documents and analytical outputs are never retained or harvested to train foundational or public AI models.

2. Information We Collect

We collect only the minimal data necessary to provide a reliable, secure user workspace:

  • Authentication Profile: When signing in via Google OAuth, we receive your email address, verified status, display name, and avatar picture. For Judge Demo access, an evaluation pseudonym is generated.
  • Structured Workspace Metadata: Document title (e.g. "Employment Agreement"), document category, context situation (e.g. "Employee"), goal, and validated analysis outputs.
  • User Preferences: Theme preference (Dark, Light, System), reduced motion settings, and default persona choices.

3. Third-Party Services & Processing

To deliver high-speed legal intelligence, LegalLens AI interfaces with verified infrastructure partners:

  • Groq Inc. (LLM Inference): Analysis requests are routed securely over TLS to Groq's high-speed inference engine for one-pass processing under strict enterprise API terms.
  • Google Cloud Platform & Firebase: Authentication identity and isolated Firestore database subcollections are secured using Google Cloud security infrastructure.
  • Vercel: Our application edge routes and static web client are hosted on Vercel's global CDN.

4. Cookies and Local Storage

LegalLens AI uses strictly necessary cookies and local storage tokens:

  • Session Cookie (legallens_session): An encrypted, HttpOnly, SameSite=Lax cookie configured to maintain your secure authenticated session for 4 hours. It cannot be accessed by client-side JavaScript.
  • Local Storage (legallens_theme): A single key used exclusively to remember your preferred UI theme and prevent unstyled flashing on page load.
  • No Tracking Cookies: We do not use third-party advertising, commercial tracking, or behavioral profiling cookies.

5. Security Safeguards

We employ multi-layered defensive security including:

  • Strict Content Security Policy (CSP) blocking unauthorized external scripts and framing.
  • Per-IP and per-user rate limiting on authentication and AI analysis endpoints.
  • Per-user Firestore collection isolation preventing cross-account access.
  • Cryptographically secure one-time OAuth state validation with automatic expiration.
